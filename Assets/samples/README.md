# Samples Swell Bass

Un dossier par catégorie. Le plugin charge chaque sample dans la catégorie de son dossier.

| Dossier | Contenu |
|---|---|
| `SUB BASS/` | Sinus / subs propres |
| `REESE BASS/` | Reese, scies désaccordées |
| `808/` | 808 longues, punchy, distordues |
| `PLUCK BASS/` | Basses courtes et pincées |

Format : WAV ou FLAC, mono de préférence, 44,1 ou 48 kHz.
Tous les samples sont accordés sur C. Les originaux sont dans `../samples-originaux/` (non publiés sur GitHub).
Nom conseillé : `Nom_Note.wav` (ex. `Long808_C1.wav`). Sans note dans le nom, la note de base est C1.
